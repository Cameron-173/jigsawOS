# jigsawOS
A set of utilities for the BBC micro:bit v1 and v2

---

Welcome to jigsawOS, a set of utility tools for both versions of the BBC micro:bit!

- v1; Function is available for both versions of the micro:bit.

- v2; Version is only compatible with v2 micro:bits. For information on identifying your model, consult this guide by the BBC:
 https://support.microbit.org/support/solutions/articles/19000067679-how-to-find-the-name-of-your-micro-bit

---

NOTICE;

This is a prototype version of the system, expect unfinished areas and bugs.
